# 4-minute demonstration plan

This is a recording script, not a completed recording.

0:00–0:30: Introduce SkillMarket, roles, stack and offer-only scope. Show the marketplace homepage and category/keyword filtering.

0:30–1:10: Register a seller, create a service with a valid price and description. Save as Published. Show edit and Draft controls. Explain that listings with offers retain their history.

1:10–1:50: Log out, register a buyer, find the listing and submit an offer with a scope and price. Show the PENDING badge in the buyer dashboard.

1:50–2:30: Switch to the seller, accept the offer, show ACCEPTED, then mark it completed. Explain that rejection is terminal and only accepted work can be completed.

2:30–3:00: Switch to the buyer, submit a rating and review, view it on the listing, and show that a second review is unavailable.

3:00–3:35: Show REST API listing search, one failed unauthorized write, and the executed automated test transcript. Explain shared services and database constraints.

3:35–4:00: Show Django Admin and the engineering reports. Clearly state which database was used, that there are no payments, and any remaining external deliverables. Finish with verified repository/demo/diagram links once available.
